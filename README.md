# Northern Territory support resource pages

Two static, source-linked support finders:

- [Housing and homelessness](homelessness/)
- [Defence members, veterans and families](defence/)

These pages do not collect or submit answers. Each contact explains its published scope, costs, source and review date. Providers confirm current eligibility, hours and availability. No live bed or appointment availability is supplied. In immediate danger, call 000.

The `homelessness/` app contains 77 verified handbook services plus three web-only contacts. The `defence/` app uses the 130-record handbook-aligned catalogue. The paired user interface shares the exact same stylesheet and components.
